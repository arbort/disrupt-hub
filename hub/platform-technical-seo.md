# Техническая SEO-гигиена платформы — для Дизрапта, не зона контентного движка

Источник: рабочий реестр «Тех. задачи», который команда SEO giga.chat вела
с агентством (окт. 2025 — июль 2026), лист получен от Арсения 2026-09-12
(`ГигаЧат - Рабочий документ.xlsx`, лист «Тех. задачи»). Это ровно то, что
SEO-агентство назвало «остальными работами по SEO» и явно исключило из
своего узкого контентного предложения (см. `HUB.md`, раздел про
SEO-команду). Здесь — не потому что это делает `hub-writer`, а чтобы не
потерять список к моменту, когда Дизрапт реально начнёт собирать
disrupt-hub.ru технически.

## Чек-лист, по категориям из прецедента

**Индексация и дубли**
- [ ] Редиректы настроены корректно (301 на канонический URL, без цепочек)
- [ ] `rel=canonical` на страницах, где возможны дубли (фильтры по продукту,
      пагинация, UGC-копии)
- [ ] `meta name="robots"` — закрыть служебные страницы (черновики, формы),
      не закрыть по ошибке страницы статей

**Карта сайта и краулинг**
- [ ] XML sitemap без ошибок, обновляется автоматически при публикации новой
      статьи
- [ ] Пагинация каталога статей размечена корректно (`rel=next/prev` или
      эквивалент), не создаёт дублей

**Микроразметка**
- [ ] Schema.org на страницах статей (Article/HowTo — E2E-гайды хаба хорошо
      ложатся на `HowTo`), на карточках продуктов
- [ ] Проверка микроразметки валидатором перед стартом индексации

**Перелинковка**
- [ ] Внутренние ссылки со страниц статей на карточки продуктов и обратно —
      без этого краулер и пользователь не доходят до глубоких страниц
      (лессон из прецедента: без перелинковки «почти невозможно внутри сайта
      дойти до страниц статей», что напрямую бьёт по ранжированию)
- [ ] Ссылки между статьями одного продукта и одного кластера тем

**Производительность и сниппеты**
- [ ] Core Web Vitals в норме до начала продвижения контента — иначе
      технический долг съедает эффект от статей
- [ ] Оптимизация сниппетов (title/description) под реальный CTR в выдаче,
      не только формальное заполнение

## Что это не отменяет

Контент-инженерия (семантика, ТЗ, статьи, UGC, синдикация) остаётся зоной
`hub-writer` — см. `HUB.md`. Этот файл — справочник для того, кто на стороне
Дизрапта возьмёт техническую сборку и поддержку сайта (вопрос пока открыт,
см. `HUB.md`, «Открытые вопросы»).
