# Disrupt-Hub — контекст для облачного агента

Этот репозиторий — **намеренно узкий срез** рабочего пространства `disrupt/`,
не весь каталог. Заведён 2026-09-13 единственно как read-only контекст для
облачного routine (Claude, запланированный запуск), который пишет черновики
статей для disrupt-hub.ru.

## Что внутри и зачем

- `hub/HUB.md` — методология контентного движка: восемь стадий, жёсткие
  правила, продуктовые запреты, конвенция иллюстраций
- `hub/briefing/*.md` — что раскрывать по каждому продукту, что нет
- `hub/topics/*.md` — бэклоги тем со статусами (пишет только по «утверждено»)
- `hub/platform-technical-seo.md` — технический SEO-чеклист
- `DISRUPT.md`, `shared/PRODUCTS.md`, `products/<slug>/PRODUCT.md` — фактура
  продуктов и бренда

## Что сознательно НЕ включено

Всё остальное содержимое `disrupt/` (креативы, баннер-кит, отчёты по
перформансу, медиапланы, brandbook, данные кампаний, xlsx с бюджетами) —
не имеет отношения к написанию статей хаба и не должно жить во внешнем
репозитории. Если понадобится что-то ещё для этой задачи — добавлять точечно,
не открывать доступ директорией целиком.

## Это не основной репозиторий

Основная рабочая среда (`ClaudeVS/`) не под git вообще — эта папка существует
только ради данного облачного агента. Изменения сюда почти всегда должны
сначала происходить в основном дереве `/Users/ars/ClaudeVS/disrupt/`, а потом
переноситься сюда точечно, а не наоборот.
