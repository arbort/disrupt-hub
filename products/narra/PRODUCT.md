# Narra

**Статус файла: стаб.** Собран 2026-09-12 с `disrupt.builders` и лендинга
`get-narra.app`. Не использовать для рекламных текстов без проверки с
Дизраптом.

## Что это

Интерактивная читалка книг с ИИ: озвучивает книгу разными голосами,
«оживляет» персонажей по их описанию из текста и даёт с ними общаться в чате.

- Формулировка с `disrupt.builders`: «Интерактивная читалка: озвучит книгу,
  оживит героев и даст с ними поговорить»
- Три заявленные механики: оживить героев (создаются по описаниям из книги) ·
  общаться с героями (чат) · слушать книги (голосовая озвучка)
- Бесплатно для бета-тестеров
- Платформы: **iOS** (через TestFlight) · **Android**
- Лендинг: `get-narra.app`

## Незакрытые вопросы

- [ ] Каталог книг: свои тексты пользователя, готовая библиотека или оба
      варианта — не указано на лендинге
- [ ] Модель после беты, лимиты
- [ ] Целевая аудитория и частотность спроса — не оценивались
- [ ] Данные по DAU/стадии воронки гипотез Дизрапта отсутствуют
